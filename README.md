# shield360.biz website

Static site. Upload the contents of this folder to the web root of `https://shield360.biz`.

| Path | Purpose |
|---|---|
| `index.html`, `styles.css`, `script.js`, `assets/` | The website |
| `install.ps1` | Server installer: `irm https://shield360.biz/install.ps1 \| iex` |
| `download/` | Generated by `Build-Downloads.ps1`. Do not edit by hand |
| `Build-Downloads.ps1` | Builds `download/` from `../server` and `../agent`. Don't upload it |

## Releasing a new version

1. Bump `version` in `server/package.json`.
2. Run `.\Build-Downloads.ps1` in this folder. It writes the zip, the agent scripts, `latest.json`, `latest.js` and `SHA256SUMS.txt`.
3. Upload `index.html`, `styles.css`, `script.js`, `assets/`, `install.ps1` and `download/`.

The package never includes `server/config.json` or `server/data/`. The build fails if either one would end up in the zip.

## Hosting requirements

- **HTTPS only.** `install.ps1` runs as Administrator, so it must never be served over plain HTTP.
- Serve `.ps1` files as `text/plain; charset=utf-8` so `irm` returns the script as text.
- Don't cache `install.ps1` or `download/latest.json` for long (5 minutes at most), so new releases take effect quickly.

To preview locally, run `python -m http.server 5510` in this folder.
