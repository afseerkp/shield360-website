Shield360 HOT System Agent
Install

Install the HOT System Agent in one command.

Open Windows PowerShell as Administrator and paste this. It downloads the agent and tray, checks the download's SHA‑256, and asks for your server address and enrollment token.

irm https://shield360.biz/hot/install.ps1 | iex

What happens

  1. Run as Administrator

    Start menu, type PowerShell, right‑click Windows PowerShell and choose Run as administrator.

  2. Answer two questions

    The agent address IT gave you, and an enrollment token from Admin › Enrollment in the dashboard.

  3. See it in the dashboard

    The PC enrolls within a minute and appears under Assets › Register with its own tag. If its name doesn't match the token's pattern, approve it under Admin › Machines & keys.

Every PC lands in the asset register

Nobody has to type the fleet in. Each enrolled PC becomes an asset by itself, with its maker, model, serial and site, and keeps its tag if it is re‑imaged. IT adds the rest.

A tag on day one

Tags such as HOT-00001 are numbered per company. A new PC sits in stock until someone is named as its owner, and the register lists it under “Needs an owner” while it checks in.

A named owner

Open the tag and choose Assign to a person. Add people under Assets › People, and mark them as left when they go; their equipment stays on the list until it is handed back.

Its whole life, recorded

Assign, return, repair (the owner is kept), move site and retire. Each step records who did it and when, in the asset's history and the audit log.

The rest of the kit

Admins add monitors, docks, phones and printers by hand, with purchase date, supplier, cost and warranty end. Warranties ending within 90 days are flagged, and the register exports to CSV for finance.

Other ways to run it

Without questions

Give the server and token up front, for remote PowerShell or a pasted runbook.

& ([scriptblock]::Create((irm https://shield360.biz/hot/install.ps1))) -Server https://agents.example.com -Token fpe_xxxx

Check first

Downloads and checks everything, and changes nothing on the PC.

& ([scriptblock]::Create((irm https://shield360.biz/hot/install.ps1))) -WhatIf

Upgrade

Run the same one‑liner on an enrolled PC. It keeps the server address, identity and queued data, and asks nothing.

irm https://shield360.biz/hot/install.ps1 | iex

Remove

Or use Apps & features › HOT System Agent › Uninstall.

& "$env:ProgramFiles\FleetPulse\Uninstall-FleetPulse.ps1"

More options: -KillList teams.exe,outlook.exe, -NoScreenshots, -InstallDir, -CfAccessClientId with -CfAccessClientSecret, and -RequireSignedTray once your tray is code‑signed.
