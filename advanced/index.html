Advanced edition

The same protection, built for a security team.

Shield360 Endpoint Advanced keeps everything in the standard edition and adds roles, single sign‑on, incidents, detection rules, and vulnerability and compliance tracking. It runs as two Windows services on PostgreSQL.

This is a preview. Install it on a spare server first, not over a server you rely on. The standard edition is still the supported release, and its downloads have not changed.

What it adds

Roles and single sign‑on

Admin, analyst and read‑only users, each with their own sign‑in. Sign in with Microsoft Entra ID or Google Workspace, pinned to your organisation.

Incidents

Open an incident from one or more alerts, give it an owner and a priority, and close it with a reason. Each priority has a response and a resolution target, and a missed target sends a notification.

Detection rules and hunting

Write your own rules on endpoint events, search process starts and connections across the fleet, and find programs that run on only a few machines.

Vulnerabilities

Missing Windows security updates and installed programs with a known CVE, flagged when CISA lists the CVE as exploited, with its CVSS score and its EPSS chance of exploitation. Deadlines per severity and risk acceptance are included.

Compliance

CIS Controls v8.1 and ISO/IEC 27001:2022 scores from what the agents already report, per control and per endpoint, with the change since last week and a CSV report.

Dashboards and a monthly report

Five dashboards, a security health index for the whole fleet, and a printable monthly posture report.

Install

There is no one‑line installer yet. Download the package, check it, and run the installer inside it from an elevated PowerShell.

  1. Create a database

    On PostgreSQL 16 or newer, create an empty database and a login that owns it. TimescaleDB is optional.

  2. Download and check

    Download the package, then compare its SHA‑256 with the one under Details.

    Get-FileHash .\shield360-advanced-*.zip -Algorithm SHA256

  3. Extract and install

    Extract the zip, then run the installer with your connection string. It prints the first admin sign‑in at the end.

    .\Install-Shield360Server.ps1 -Connection "Host=localhost;Database=shield360;Username=shield360;Password=..."

With HTTPS

Without a certificate the server listens on plain HTTP, which is only suitable for a first look. Give it a certificate to serve HTTPS.

.\Install-Shield360Server.ps1 -Connection "..." -Port 8443 -CertificatePath C:\certs\shield360.pfx -CertificatePassword ...

Upgrade or remove

To upgrade, run the installer from a newer package with the same parameters. To remove the services and the firewall rule (the database is kept):

.\Install-Shield360Server.ps1 -Uninstall
